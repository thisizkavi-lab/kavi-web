# Kavi

This is my personal portfolio website.

![Website Demo](assets/demo.png)

## Tech Stack

Built with React (Vite) and Tailwind CSS.
Content is managed using Markdown files.

## Run Locally

```bash
git clone https://github.com/thisizkavi-lab/kavi-web.git
cd kavi-web
npm install
npm run dev
```
